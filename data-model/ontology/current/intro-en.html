Introduction back to ToC

The SKG-IF Service Extension (SRV-O) defines entities for modelling Service-type objects in the Scientific Knowledge Graphs Interoperability Framework.

A Service is a type of software application or component that provides specific functionality or operations over a network, often via the internet, and is typically accessed through an interface such as an API or a web application.

The properties and classes in this extension were informed by several existing schemas and catalogues:

  • The CMDI schemas for tools and services used in the VLO catalogue
  • The SSH Open Marketplace (SSHOMP) catalogue
  • The European Language Grid (ELG) catalogue
  • The CLARIN Language Resource Switchboard schema
  • The Schema.org SoftwareApplication type
  • The EOSC Service Profile (versions 4.1 and 5.0)

This extension is developed in the context of the OSTrails project.
